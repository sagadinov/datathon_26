# Архитектура

Сервис анализирует видеозапись кассы полностью локально (CPU достаточно) и возвращает вердикт,
список нарушений с таймкодами, кадрами-доказательствами, описанием и нормативной ссылкой.

## Конвейер обработки одного видео

```
video.mov
  │  ffmpeg: 2 кадра/с, длинная сторона 640 px, кэш кадров на диске по хэшу файла   (frames.py)
  ▼
Детектор с открытым словарём — Grounding DINO tiny (Apache-2.0), CPU                 (detect.py)
  │  14 классов по текстовым подсказкам: person, hand, cash, money_bag, bag, cup, jacket,
  │  laptop, phone, safe, safe_door_open, desk, door, counter_machine, book.
  │  Каждому боксу назначается ОДНА фраза по максимуму sigmoid её токенов (без слияния
  │  фраз), затем NMS по классам. Кэш детекций на диске                             (detect_cache.py)
  │  Бюджет времени: скорость измеряется на ходу, при нехватке времени шаг кадров растёт.
  ▼
Трекинг людей — жадный матчер IoU + расстояние центров, буфер потери 3 с             (track.py)
  ▼
Авто-зоны сцены — без пиксельных констант                                            (zones.py)
  │  Статичные объекты (стол, ноутбук, счётная машинка, сейф, дверь) = медианы кластеров
  │  боксов за весь ролик. «Место кассира» = медиана боксов людей, сидящих за
  │  ноутбуком/машинкой. Зоны выражены относительно этих боксов → другой ракурс в тесте
  │  даёт другие пиксели автоматически.
  ▼
Таймлайн состояния сцены по кадрам                                                   (state.py)
  │  люди: кто кассир, на месте ли, расстояние до стола (в высотах стола), у двери, у сейфа;
  │  предметы на столе (центр бокса внутри стола) с score; дверца сейфа (score, гейт по
  │  боксу сейфа); яркость кадра (свет выключен) и доля белых пикселей в боксе ноутбука
  │  (экран светится); руки ниже кромки стола.
  ▼
Новый предмет на столе — сравнение с фоном стола                                      (blob.py)
  │  Медианный фон стола за первые 10 с (люди маскируются), разность в Lab с вычитанием
  │  локального среднего, порог по MAD шума ролика, компонента 40–600 px², стабильная
  │  ≥3 кадра. Так видна пачка 12–25 px, которую детектор не находит. Отключается USE_BLOB=0.
  ▼
Движок правил T1–T10                                                                  (rules.py)
  │  Чистые функции над сериями: присутствие объекта = k из n последних кадров,
  │  минимальные длительности в секундах, относительные пороги (например, «открытая
  │  дверца» = score выше собственного фона ролика на 0.25). События → слияние, до 4 на видео.
  ▼
Описание (только видимое, по шаблону) + 1–3 кадра JPEG q=80 с рамками + норматив    (describe.py, evidence.py)
  │  Источник: docs/legal_sources.json — пункты Правил НБРК № 231, сверенные с текстом.
  │  VLM (Qwen2.5-VL через локальный vLLM) подключается только при наличии GPU и только
  │  для подтверждения кандидатов; без GPU шаг пропускается (деградация, не отказ)  (vlm.py)
  ▼
JSON по схеме ТЗ (+ дополнительное поле rule в каждом нарушении)
```

## Сервис

- `src/api/main.py` — FastAPI: `POST /api/v1/analyze` (multipart `file`) → `job_id`;
  `GET /api/v1/jobs/{job_id}` → `processing | done | failed` + результат; заголовок `X-API-Key`.
- `src/api/worker.py` — очередь в процессе, N воркеров, каждое задание = подпроцесс
  `python -m src.pipeline.run` с жёстким таймаутом; частичный результат вместо `failed`
  при превышении бюджета; состояние заданий на диске, повторная постановка после рестарта.
- `src/ui/static/` — интерфейс на чистом HTML/JS, отдаётся тем же процессом по `/`.
- Публикация: ngrok со статическим доменом (`scripts/tunnel.sh`), запуск в tmux
  (`scripts/start_service.sh`). Хостинг — логин-нода кластера (входящие соединения закрыты,
  Cloudflare Tunnel заблокирован файрволом, ngrok по 443 работает).

## Локальность и переносимость

- Веса скачиваются один раз (`scripts/download_models.sh`) в `models/hf`; при обработке
  `HF_HUB_OFFLINE=1`, `TRANSFORMERS_OFFLINE=1`, сетевых вызовов в коде обработки нет.
- Лица не распознаются: люди — класс `person`, роли (кассир/посетитель) выводятся из
  положения относительно стола.
- Лицензии: Grounding DINO — Apache-2.0; transformers, FastAPI — Apache-2.0/MIT; ultralytics
  (AGPL-3.0) намеренно не используется.

## Производительность (CPU, 32 потока)

| этап | время |
|---|---|
| извлечение кадров | ~0.6 с на 25 с видео |
| детекция | 0.6–0.75 с/кадр при 2 кадр/с |
| трекинг + зоны + правила | < 0.1 с |
| ролик 60 с | ~80 с; ролик 145 с | укладывается в бюджет 170 с за счёт увеличения шага |

## Оценка

`eval/evaluate.py` на 42 размеченных роликах: вердикт (recall по нарушениям, FP на чистых),
таймкод (|Δt|, доля ±3 с/±5 с), тип (прокси-разметка команды), время. Результаты каждого
прогона — `eval/results/<время>_<git-sha>.json`. Устойчивость — прогон на зеркальных,
повёрнутых на ±10° и уменьшенных до 480 px копиях (`scripts/make_augmented.py`).
