## 3. Общие примитивы для `state.py` (без них ни одно правило не работает)

Все пороги ниже — в единицах кадров при 2 fps (`_sec(tl, s)`) и относительных размерах (ширина стола,
высота сидящего кассира), пиксели даны только как иллюстрация для кадра 350×640.

### P1. `in_room(p)` **(new)** — человек в комнате, а не за стеклом
- Люди за стеклом детектируются во ВСЕХ роликах (score до 0.73, X-18) и получают флаги `d`/`D`/`S`/даже `C`/`s`
  (X-5, X-11, X-13, X-15, X-22, X-25, X-26, X-28, X-29, X-32, X-33 — кассир снаружи за стеклом считается «на месте»).
- Определение: `box.y2 >= floor_line`, где `floor_line = door_zone.y2 - 0.02*H` (камера A: порог ≈278–280 px —
  за стеклом y2 ≤ 274, внутри ≥ 280 (X-18); камера B ≈290 px (X-11, X-12); X-32 door.y2 = 342). Fallback без двери:
  `box.y2 >= desk.y0 - 0.1*desk_h` (X-39: 261; X-43: 276; X-45: 264; за стеклом 188–260).
- Плюс `box_h >= 0.5 * cashier_ref_h` (X-18: кассир 162 px, сидящий клиент 89 — проходит, женщина за стеклом 60–75 — нет).
- Гистерезис 2 кадра: ноги клиента перекрывает машинка (X-18 20.5–21.0 y2 падает до 284–285).
- Дополнительно OUTSIDE, если бокс целиком внутри `door_zone` и `box.y1 < door.y0 + 0.38*door_h` (X-13/X-15: снаружи
  y1 ≤ 121, внутри стоя y1 ≥ 126–153, сидя ≈200).

### P2. Дедупликация людей и фильтр призраков **(new)**
- Удалять person-бокс, если IoU ≥ 0.45 или содержание ≥ 0.7 внутри более уверенного person-бокса (X-43: IoU 0.54
  проходил NMS 0.6 — дубликат «верхней половины» кассира; X-3, X-8, X-14 — дубликат 60 с, X-24, X-26, X-27, X-32, X-33, X-45).
- Игнорировать треки короче 3 кадров (1.5 с) с `anchor_overlap = 0` и `desk_gap ≥ 0.4` в зоне двери/стекла (отражения:
  X-12 7 раз, X-20, X-22, X-27 ×4, X-25).
- Считать людей по кадру после дедупликации, а не по track id: id переиспользуются (X-4 id 3 = оба клиента, X-18 id 4,
  X-19 id 2 = оба клиента, X-38 id 1 = оба клиента, X-17 id 2→3 на двери, X-3 id 2→3→4).

### P3. Кассир: один раз на видео + состояния `at_desk / seat_vacated / away / exit` **(new)**
- `is_cashier` по кадру ломается: зоны зеркальны (X-4: seat на стороне клиента → каждое C/s-правило инвертировано),
  флаг C на клиенте в 45% кадров (X-5/48), id-switch сидя (X-24 3.5 с, X-26 8.0 с, X-32 10.5, X-33 10.5), `None` (X-30).
- `cashier_track` = трек с максимальным временем бокса-центра внутри `cashier_seat` (или `anchor` при его отсутствии)
  среди `in_room`-треков; слияние id, передающих друг другу бокс в соседних кадрах (IoU > 0.4); гистерезис смены 4 кадра.
  Fallback без seat/laptop (X-30, X-31): первый `in_room`-трек, перекрывающий `counter_machine` ≥ 2 кадра или сидящий
  в кресле, касающемся стола.
- `cashier_at_desk(i)`: любой дедуплицированный `in_room`-бокс с IoU(seat) ≥ 0.3 **или** `desk_gap ≤ 0.10` (не по id).
- `seat_vacated(i)`: высота бокса ≥ 1.3–1.4 × эталонной сидячей (медиана первых 10 с присутствия: X-28 75→130 px,
  X-12 82→126–137) **или** IoU с эталонным сидячим боксом < 0.3. Не использовать флаг `s`: он держится стоя
  (X-28 до 9.0 с, X-12 у сейфа, X-20 у сейфа, X-21 у шкафа).
- `cashier_away(i)`: `not cashier_at_desk` **и** `not attending_safe` (P4) **и** не у машинки (рука в `counter_machine`).
  Относительный порог: `anchor_overlap < 0.6 × бегущей медианы` (сидя 0.3–0.4 → away при ≤ 0.2: X-24 5.0 с, X-26 9.0 с).
  Минимум 4 кадра (2 с) против блипов 1–4 кадра (X-14 1.5–4.0, 21.5, 26.5–29 с).
- `exit(t_exit)`: центр бокса кассира входит в `door_zone` с `y2 ≤ door_zone.y2 + 20 px`, затем нет `in_room`-кассира
  ≥ 2 кадра (X-11 18.0; X-22 16.5; X-28 10–11.5; X-15 15.5; X-26 15; X-24 10.5; X-13 61; X-23 14.5; X-29 13; X-27 22).
  Бокс за стеклом после выхода (`in_room` = false) — отсутствие, а не возврат. Если ролик кончается < 3 с после
  выхода — условие «пусто» считается выполненным при ≥ 2 пустых кадрах (X-28: только 15.5–16.0 пусто).

### P4. `attending_safe(i)` **(new)** — кто-то у сейфа/шкафа
- `at_safe` требует x-перекрытие ≥ 0.5 ширины сейфа → никогда не ставится при реальной работе с сейфом (X-48 0.22–0.35,
  X-39 0.22–0.35, X-19 бокс кончается 28 px левее зоны, X-21 стоит левее зоны, X-13/14/15 зона на двери).
- Новое: person x-перекрытие ≥ 0.25 ширины сейфа **или** край бокса в пределах 0.3 × ширины сейфа от края сейфа
  (X-48: 218–246 vs 229) **или** `hand`-бокс (score ≥ 0.25) с центром внутри `expand(safe, 1.5, 1.4)` (X-39: 0.25–0.33
  ровно во время двух обращений к сейфу) **или** кассир сидит в пределах одной высоты стола от сейфа и его бокс
  расширяется в сторону сейфа (X-35: x1 199–202 → 254–268; X-39).
- Требует исправленного якоря сейфа (P8). При `safe presence < 0.5` → `attending_safe = False` везде и T3 отключён.

### P5. Фоновые объекты, новые объекты, статичные пятна на столе **(new)**
- **Фон (baseline):** кластер боксов одного класса, присутствующий (IoU ≥ 0.5–0.7 с медианой) в ≥ 70–80% кадров
  **или** в первых 2–3 с ролика, — мебель/оборудование; никогда не стартует событие. Убивает: `money_bag` на машинке

## 4. Спецификации по типам

Формат каждого типа: ролики → видимое определение → стартовый cue (`timecode_sec`) → сигналы → логика с порогами →
исключения (нормальное поведение чистых роликов) → пробелы детектора.

### T1 — Наличные/ценности без присмотра
**Ролики:** X-4 (57, вариант B), X-15 (15, A), X-26 (9, A), X-38 (33, B).
**Определение (видимое):** деньги или денежная сумка лежат на столе, и (A) кассир покинул рабочее место (не у стола, не у
сейфа) ≥ 2–3 с, никого другого у стола; или (B) предыдущий клиент ушёл, а в комнату входит следующий человек, пока
наличные предыдущего всё ещё лежат на столе (кассир может сидеть на месте).
**Стартовый cue:**
- A: первый кадр финального «ухода» — кассир не у стола и не у сейфа (X-26: встаёт 9.0; X-15: отворачивается от шкафа
  к двери 14.0 — стояние у шкафа 10–13.5 с не считается уходом). Разметка колеблется между «встал» (X-26) и «дошёл до
  двери» (X-15); правило «уход без остановки у сейфа» даёт |Δ| ≤ 1 с в обоих.
- B: кадр пересечения порога новым человеком (X-4 57.0; X-38 32–33), fallback — подход к столу (X-38 35, X-4 58–59).
**Сигналы:** `valuables_on_desk` = `new_desk_object(cash|money_bag|bag|book, 0.30, 2)` ∪ `desk_blob` (P5);
`cashier_at_desk`, `cashier_away`, `attending_safe` (P3/P4); `client`, `entered`, `left` (P9); `in_room` (P1).
**Логика:**
- T1-A: run по кадрам `valuables_on_desk ∧ cashier_away ∧ ¬attending_safe ∧ ¬(другой in_room-человек с desk_gap ≤ 0.1)`;
  длина ≥ 6 кадров (3 с) **или** run доходит до `exit` / конца ролика (≥ 2 кадра). `timecode = t(run[0])`.
  Проверка: X-26 run 9.0→19.8 (трек пропал 18–19.5 = away) → t = 9.0; X-15: 8.0–9.5 (4 кадра) < 6 → сброс у шкафа
  10–13.5 (`attending_safe`) → run 14.0→20.9 → t = 14.0; X-24 без ценностей → не T1 (см. T2).
- T1-B: `valuables_on_desk` статичен ≥ 8 кадров (4 с) ∧ ни одного `client` ≥ 4 кадра (2 с) ∧ событие `entered` нового
  не-кассира → `timecode = t(entered)`; событие держится, пока объект лежит. X-4: пачка с 44 с, клиент 1 ушёл 52–53,
  вход 57.0; X-38: пачка с 26.5, клиент 1 ушёл 28, вход 32–33.
- Описание: «пачка купюр лежит на столе с N с; кассир вне рабочего места с M с / следующий клиент вошёл в K с».
  Кадры: момент появления объекта, кадр `timecode`, последний кадр с объектом.
**Исключения (чистые):**
- X-5/48: деньги убраны в сейф 46.5–52.5, стол пуст при входе второго клиента 63.5–68 → нет объекта → тишина.
- X-14: пачки на столе 31.5–45.5 (`cash` 0.40–0.50, 28 кадров), кассир у сейфа спиной к столу 34.5–43 → `attending_safe`
  → тишина; 43.5–46 она у стола.
- X-10, X-43, X-45, X-19, X-3, X-38 6–23, X-35 7.5–9: деньги на столе при сидящем кассире / при клиенте → `cashier_at_desk`.
- Купюры в бункере/лотке машинки (X-19 13.5–18, X-21 9.5–18.5, X-39, X-43–46) — внутри маски `counter_machine`.
- `money_bag` на машинке/телефоне после ухода кассира (X-11 23–24, X-12 37.5–42, X-23 12.5–15 `cash` 0.32–0.42, X-25,
  X-27, X-29, X-31 0–11 с пустая комната) — baseline P5.
- X-16: сумка инкассатора на столе при присутствующем инкассаторе → есть `in_room` не-кассир у стола.
- X-18: карта 12×10 px (`cash` 0.38 один кадр) при входе второго клиента → `cash ≥ 0.30` в ≥ 2 из 6 кадров и
  ширина ≥ 15 px не выполнены → T1-B молчит (событие — T4).
- Пропуск трека кассира на 1 кадр (X-46 10.0 с, X-20 9.5/11.0) — держать состояние 2 кадра.
**Пробелы детектора:** наличные на столе почти не детектируются (X-26 2/25 кадров, X-38 9/65, X-4 0 кадров в 44–55.5 с,
X-15 сумка = `cash`/`book`, не `money_bag`); `money_bag` постоянно на машинке; `cashier_near` инвертирован при зеркальных
зонах (X-4); «у стола» через `desk_gap` держится у двери и за стеклом (X-24, X-26, X-15).

### T2 — Уход с рабочего места без закрытия
**Ролики:** X-11 (18), X-22 (14), X-28 (7), X-24 (8, вариант «вещи остались»; увер. 0.5).
**Определение:** кассир уходит от стола и из помещения, оставив рабочее место незакрытым: ноутбук открыт с горящим
экраном (X-11 — в темноте после выключения света; X-22 — тёмно-синий горящий экран, крышка наклонена, но открыта;
X-28 — голубовато-белый экран), либо на столе остаются личные/посторонние предметы (X-24: стакан, журнал, открытая крышка).
**Стартовый cue:** начало финального ухода (как в T1-A): X-28 встаёт 6.5–7.0 → t = 7; X-24 отходит 6.0 (встала 5.0 с
руками на столе) → t = 5–6; X-22 поворот от сейфа к двери 13.5–14 (стояние у сейфа 9–13.5 — `attending_safe`) → t = 14;
X-11 после шкафа/выключателя 11.5–16.5 идёт к двери 16.5–17.5 → t ≈ 17 (дверь 18.0). Fallback — `t_exit`, всегда в ±3 с
(X-11 18, X-22 16.5, X-28 10, X-24 10.5).
**Сигналы:** `cashier_away`, `exit` (P3), `screen_state` (P6), `lights_off_event` (P7), `new_desk_object(cup|book)` (P5),
`in_room` (P1).
**Логика:**
- Run `cashier_away ∧ ¬attending_safe` ≥ 6 кадров (3 с) или до `exit`; событие подтверждается, когда (а) `exit` произошёл
  **или** кассир отсутствует ≥ 8 с, **и** никто другой не сел за стол в течение 10 с (другой человек у стола ≠ отмена).
- Условие «не закрыто» (любое): `screen_state ∈ {active, dim}` в ≥ 50% кадров окна [t_exit − 2 с, конец] и крышка
  открыта (h/w ≥ 0.9) **или** `lights_off_event` ∧ `screen_on`(ON*) после него (X-11) **или** на столе остаётся
  `new_desk_object(cup ≥ 0.35 | book ≥ 0.40)` ≥ 8 из 10 кадров после ухода (X-24: cup 0.37–0.47, book 0.41–0.49 до конца).
- `timecode = t(run[0])`; кадры: t, t_exit, последний кадр (пустая комната с горящим экраном/предметами).
- Приоритет описания: «кассир встал в N с и вышел в K с; ноутбук открыт, экран горит / на столе остались стакан и журнал».
**Исключения (чистые):**

  Дополнительно: `lights_off_event` ∧ пустая комната ≤ 15 с ∧ нет наличных на столе за 20 с → подавлять T1/T2/T3 в окне.
- X-23: экран 145 → 106 (заставка) в 4.5 с, выход 14.5, комната пуста 3.5 с при включённом свете — чистый. По яркости
  неотличим от X-22 (115–127 vs 105–115). Решение: при `dim` отправлять crop экрана ×3 в VLM («окно приложения /
  экран блокировки / выключен?»); без GPU — порог mean ≥ 115 как `lit` (X-22 проходит, X-23 нет) с пометкой риска.
- X-29: блокировка 5.5–6.0 (154→82), заставка 77–90 = `off` → тишина; X-27: экран 72–80 → тишина; X-25: экран тёмный,
  предметы убраны в сейф до выхода → тишина; X-13 58–62: экран тёмный, свет включён → тишина.
- X-21 0–8, X-30 11–13.5, X-31, X-32, X-33: кассир не у места при тёмном/закрытом/отсутствующем ноутбуке; пустая комната
  в начале ролика (X-30/31/32/33, X-40) — нет перехода «присутствовал → ушёл» → тишина.
- X-45: `scr=ON` на спинке кресла — требовать `presence(laptop) ≥ 0.7`, иначе `unknown` → T2 только через VLM.

### T10 (new, «Иное») — Дверь кассы не закрыта/не заперта при входе

**Исключения:** клиент, входящий при присутствующем кассире (все ролики с клиентами) — `room_empty_before` ложно;
