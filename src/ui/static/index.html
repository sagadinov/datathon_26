ForteBank: контроль кассовой дисциплины по видео

Загрузите запись с камеры кассы. Сервис проанализирует её локально и покажет признаки возможных нарушений: таймкод, кадры и нормативное основание (акты НБРК, adilet.zan.kz).

Проверка видео

Ключ сохраняется только в этом браузере.

Перетащите видео сюда или выберите файл

Форматы .mov и .mp4. Одна камера, одна касса; обработка занимает до 3 минут.

Запросить результат по номеру задания

Если связь прервалась или страница была перезагружена, результат можно получить по номеру задания без повторной загрузки видео.

Анализ выполняется локально, без облачных сервисов. Лица не распознаются: люди учитываются только как «человек в кадре».
